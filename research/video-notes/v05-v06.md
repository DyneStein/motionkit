# v06 — "Apple history — one continuous morph" (Made in After Effects by **Bentomotion**) — 1276x718, 103.8s, ~76 BPM ambient
**Style family:** ⭐⭐ *Shape-morph continuum / flat-icon metamorphosis.* **This is THE reference for "liquid, nothing cuts, everything melts into the next."** Detector: 0 real cuts after the first second; median frame-diff only 1.0 (very calm).
- **Canvas:** pale lavender #E8E3EF flat bg, never changes (constant canvas = continuity anchor). Objects centred, ~25–40% frame height. No text except end credit.
- **Sequence (each morphs into the next):** black dot → giant swoosh stroke (camera flies through a "?"-curve) → handwritten "hello." (Macintosh) with soft white radial glow → tiny Macintosh 128K → CD disc → disc **liquefies**: white bubbles orbit inside, an arc-ring grows and darkens into → iPod click wheel (grey, labelled MENU ⏮ ⏭ ▶⏸) → shrinks to white home button ring → black Touch ID button → pink **fingerprint** (stroke draw) → Face ID brackets (blue, face icon) → blue glossy sphere → ✓ check circle → pill toggle / AirPods-ish capsule shapes split → Magic Mouse pair orbit with colour dots → **5 iMac G3 coloured cups rotating in a pentagon** → colours drain to white, shapes thin into **black line-wedges** (rotation never stops) → grey disc → Mac Pro "cheese grater" → Apple-logo square → orange slider bar → coloured feather/fan strokes (iMac 2021 colours) splay into **X** → white long lines (Apple Pencil) slide & cross → thin line traces → EarPods cord **draws as a figure-8 path** → AirPods → AirPods case closes → Siri waveform (pink/blue) → Siri orb inside a **spirograph white petal ring** → HomePod Mini → Apple-TV remote (shape scales past camera) → Apple TV box → "tv+" wordmark → Find My radar (green, sweep) → camera bump circles inside **rounded-rect outlines that rotate** (iPhone X camera) → white flash → app-icon outline grid (rounded squares, delete "x" jiggle) → icons **fan out in 3D perspective as a card stack** → Music icon → Breathe app teal **flower (6 overlapping circles bloom)** → Activity runner → Activity rings draw → red dot → heart outline → filled heart beats → Watch side view → Watch band → **grid of 15 watches** (scale-out reveal) → watch face → coral iPhone XR → **fan of iPhones (colour lineup)** → coloured ticks radial burst (loading spinner) → "Made in After Effects" → "by Bentomotion" → ⚡ logo.
- **Morph techniques identified (dense 10fps strips):**
  1. **Silhouette bridge** — successive objects share an outline (circle → disc → wheel → button → ring). Scale + fill-colour crossfade + inner detail fading = morph.
  2. **Continuous rotation carrier** — a group keeps orbiting/rotating at constant angular speed through the change (iMac cups → white wedges → black line-ticks), so the eye never sees a reset.
  3. **Desaturate → reshape → recolour** — colour drains to white/grey *before* geometry changes, then new colour fills after (hides the topology change).
  4. **Satellite bubbles** — small white circles orbit & merge into rings to "melt" a disc into a wheel.
  5. **Stroke draw-on/draw-off** (trim paths) for fingerprints, cords, Pencil lines.
  6. **Scale-through camera** — object grows past frame edges; its inner detail becomes the next canvas (remote → TV).
  7. **Multiplication** — one object → grid/fan of variants (watch grid, iPhone fan) = "range/lineup" beat.
- **Easing:** everything ease-in-out (cubic/expo-ish), long holds avoided — always something in motion, but slowly. Overshoot only on pops (heart beat).
- **Lessons:** ⭐ constant bg colour, centred subject, flat vector icons with subtle gradient/shading, **one object at a time evolving**. This is the archetype for a *"Morph Continuum"* kit style.
