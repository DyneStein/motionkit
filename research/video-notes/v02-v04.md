# v02 — "Darkside" lyric video in desktop-UI world (by Subz Motion) — 720x720, 37.8s, ~86 BPM (Alan Walker)
**Style family:** *Screen-world / UI-as-stage lyric video* — **0 hard cuts in 38s** (detector-verified). One continuous virtual camera.
- **Concept:** lyrics typed/rendered *inside real-looking OS & app UI*: Spotify-style player → Google search bar (lyric typed with blinking caret "I know that you can feel") → Windows Explorer ("No secrets — Stored locally") → After Effects + VS Code (`const lyrics = "So fool me like I'm dreaming"` code with syntax colours) → circular avatar badge with **text-on-a-circle** spinning ("TAKE ME THROUGH THE NIGHT") → Google-Maps-like map with Alan-Walker "W" logo pins forming a path ("FALL INTO THE DARK") → Windows quick-settings (Wi-Fi tile, brightness slider dragging) → Maps place card "Monument to the Revolution…" → circular photo with curved text "ON THE DARK SIDE" → **newspaper** "The Morning Chronicle" headline typing "FALL INTO THE DARK SIDE" → TikTok comment UI → Spotify lyrics view → newspaper placed on a wooden table, camera pulls up & away, fade to black.
- **Transition grammar (the gold):** every scene change = a **camera move through UI**: zoom into an element until it fills frame (search bar → its "+" button → next scene), whip-pan with heavy **motion blur** (6.5s blue streak), push-through a circle mask (code → circular avatar, 12.5s), rotate-in 3D (newspaper tilts in Y, 32–34s), pull-back reveal (newspaper on desk). Elements *become* the next scene → **match-cut/morph continuity**.
- **Camera:** constant 3D tilt (UI planes rotated ~10–25° in X/Y, perspective), slow drift + rotation, punch-ins on beat, rack-focus blur on far planes.
- **Typography:** each lyric is a "typewriter with caret" OR big bold word-stagger (FALL / FALL IN / FALL INTO with lime-green text + dark outline on dark map), circular text paths, serif newspaper headline.
- **Colour:** dark mode UI (#1e1e1e), Spotify gold/brown gradient for lyric view, map purple/maroon night tint shifting to pale mint daylight (time-of-day change as a transition), lime green accents.
- **Audio-sync:** every syllable has a visual event; brightness/volume sliders move to the music.
- **Lessons:** ⭐ "no cuts" achieved by *zoom-through* & *element-becomes-scene*; motion blur on fast moves; 3D-tilted flat UI; typewriter captions with caret; circular text badge; end with pull-back + fade.
