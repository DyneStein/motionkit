# v28 + v29 — "Google Drive — Save everything, share anything" (two iterations of the same piece) — 1280x720 / 1080x608, ~16s each, ~80 BPM
**Style family:** ⭐ *Single-element UI micro-interaction story — one floating glass card that keeps morphing.* 0 hard cuts in both. Perfect "how to animate a UI flow without cuts" reference.
- **Logo open:** v28 — rainbow-tinted soft gradient bg flashes behind Drive logo, wordmark "Drive" wipes out from logo with blur; v29 (refined) — Drive's 3 coloured strokes **fly in as motion-blurred streaks and lock into the triangle logo** on pale lavender-white #EEF0FA.
- **"+ New" button:** a glass pill with **coloured glow ring** (v28: purple/pink halo pulses like a ripple; v29: soft blue halo on white). Cursor (hand) taps → button **squishes** (scale 0.92) → **morphs** (scales, rounds, tilts in 3D) into a dark glass dropdown card (Upload file / Scan document / Take a photo / Upload folder). Background switches **white → black with a blue radial glow** during the morph (v29) — *bg luminance flip carried by the element morph*.
- Hover highlight bar glides between menu rows; click "Upload file" → card **morphs into a square tile** "↑ Upload file" → coloured file icon **pops in with a purple glow & glitch** → tile morphs into a **"New Folder" dialog** (text field types "My project" / "Request a project", Cancel / Upload buttons) → click Upload → dialog tilts & morphs into an **upload progress card** ("Your files are uploading", two file rows with **green progress bars filling** → ✓ dots) → card **shrinks into a green pill** → pill becomes a **✓ check in a circle** with green radial glow "Successful" / "Success!!!" ⭐.
- **Card physics:** every state change = the same card resizing with **spring overshoot + 3D tilt (rotateX/Y ~10–15°) + slight rotation**, then settling flat. Cursor movement uses ease-in-out arcs; hover → press scale-down → release.
- **Background:** black with a **soft blue radial glow + subtle concentric rings** behind the card (the glow colour changes with state: blue → green on success).
- **Outro:** flash to pale lavender; "Save everything, share anything." word-by-word with blur (v28) / "Keep everything. Share anything." (v29) → fade.
- **v28 → v29 diff (what the creator improved):** lighter opening, logo built from streaks instead of fade, more consistent glow, smoother morph (fewer pops), bigger cursor motion blur, white→dark flip timed to the click. **Lesson: polish = continuity of the single element + light-dark flip on the action beat.**
- **Lessons:** ⭐ "one card, many states" morph; state-coloured glow; spring + tilt on each state change; success-check finale.
